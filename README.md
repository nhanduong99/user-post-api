# User Post API

## Getting Started

1. **Start the services with Docker Compose**

   Open your terminal and run the following command in the project directory:

   ```bash
   docker compose up -d
   ```

   This command will start all required services (app, database, etc.) in the background.

2. **Import the Postman Collection**

   - Open [Postman](https://www.postman.com/downloads/).
   - Click **Import**.
   - Select the collection file:  
     `postman/User Post API.postman_collection.json`
   - After importing, you can use the predefined API requests to test the endpoints.

---

**Notes:**  
- Make sure Docker is installed on your machine.
- It may take a few minutes for all containers to be fully up and running before you can use the API.

---

If you encounter any issues starting or using the API, please open an issue in this repository for support.
